# Elpris SE4

A small web app showing electricity prices for SE4 (southern Sweden): the price right now, today and tomorrow every 15 minutes, and a 7-day estimate.

Everything runs in the browser. Each time the app opens it fetches published prices from elprisetjustnu.se, weather observations from SMHI and forecasts from MET Norway, then calculates the estimate. No server or account is needed.

Install on a phone: open the site in Chrome, then menu > Add to Home screen.
